## About The Project

Bee Swarm Simulator Trader is a simple, fan-made web application designed for players of Bee Swarm Simulator on Roblox to create clean and shareable trade lists. Rather than tracking values or automating exchanges, this tool focuses on organization and presentation—allowing players to list items they have available "For Trade" and what they're "Looking For."

The application supports core in-game items such as Beequips, Stickers, Cub Buddy Skins, and Vouchers. Users can quickly build their lists by selecting items from categorized interfaces and view a clean, exportable visual representation of their trading setup.

The project is built with modern web tools including React, TypeScript, and Vite. Static item data and images are used to recreate a visually familiar and responsive interface for the Bee Swarm Simulator trading community.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Make sure you have the following installed:

- Node.js (v18 or later recommended)
- npm or yarn

### Installation

1. Clone the repository:

```bash
git clone https://github.com/zhenga8533/bss-trader.git
cd bss-trader
```

2. Install dependencies:

```bash
npm install
# or
yarn install
```

3. Run the development server:

```bash
npm run dev
# or
yarn dev
```

4. Open your browser and navigate to http://localhost:5173 to see the app in action.
